# Samsung · Мотивации региона

Публичный сайт: https://nikname0011.github.io/samsung-motivation-dashboard/
Репозиторий: https://github.com/nikname0011/samsung-motivation-dashboard

## Обновление данных

Пришлите новые Excel-файлы в этот чат. Я подготовлю обновлённый `site-data.js` для сайта. Исходные книги в публичный репозиторий не загружаются.

Для ручной генерации данных установите зависимость и запустите:

    python3 -m pip install -r requirements.txt
    python3 refresh_data.py

Скрипт ищет книги в родительской папке. Результат сохраняется в `site-data.js`.

## Доступность данных

Сайт и `site-data.js` публичны. В данных содержатся результаты продаж и вознаграждения сотрудников 16 магазинов региона. Исходные Excel-книги остаются локальными.

## Публикация

GitHub Pages публикует корень ветки `main`. После обновления файлов сайта публикация происходит автоматически.
