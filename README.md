# Samsung · Мотивации региона

Статический сайт. Публиковать в GitHub Pages нужно только содержимое этой папки `samsung-portal`, не родительскую папку с исходными книгами.

## Обновление данных

Исходные Excel-книги не входят в репозиторий. Скрипт читает `Мотивации_26_SM.xlsx` для четырёх действующих мотиваций и `Мотивации SAMSUNG 2026_СВОД.xlsx` для годового накопительного рейтинга. Результат записывается в `site-data.js`.

Чтобы обновить сайт, отправьте сюда в чат новые Excel-файлы. Я сформирую свежий `site-data.js`, проверю его и подготовлю публикацию. Исходные Excel-книги в репозиторий не загружаются.

Для ручного обновления установите зависимость и сформируйте свежий файл данных:

```sh
python3 -m pip install -r requirements.txt
python3 refresh_data.py
```

По умолчанию скрипт ищет книги в папке уровнем выше. Если они находятся в другом месте, передайте пути явно:

```sh
python3 refresh_data.py "/путь/Мотивации_26_SM.xlsx" "/путь/Мотивации SAMSUNG 2026_СВОД.xlsx"
```

При ручном обновлении публикуйте только подготовленный `site-data.js` вместе с необходимыми файлами интерфейса.

## Доступ

Страница и файл `site-data.js` будут публично доступны всем, у кого есть ссылка. В `site-data.js` находятся персональные результаты и вознаграждения, отобранные для 16 магазинов региона. Исходные Excel-книги исключены через `.gitignore`.

Публичная страница не содержит форму загрузки или пароль. Обновлять сайт сможет владелец репозитория и другие пользователи, которым владелец сам выдаст право записи. Пока публичный репозиторий и публикация сайта не созданы.

## Публикация

Публиковать только содержимое папки `samsung-portal`. Включить GitHub Pages для корня основной ветки. Исходные книги остаются вне репозитория: веб-странице нужен только подготовленный `site-data.js`.
